# RAG سىستېمىسى (كۆپ مەنبەلىك قوللاش)

بۇ تۈر پۈتۈنلەي يەرلىك ھالدا ئىشلەيدىغان **Retrieval-Augmented Generation (RAG)** سىستېمىسىدۇر. PDF، Word، PowerPoint، رەسىم، تېكىستلىك ھۆججەتلەر ۋە MSSQL سانلىق مەلۇمات ئامبىرى قاتارلىق ھەر خىل مەنبەلەرنى ئىشلىتىپ، تەبىئىي تىلدا سوئاللار سوراپ، ھۆججەتلەرگە ئاساسلانغان جاۋابلارنى ئالالايسىز.

سىستېما پۈتۈنلەي **يەرلىك** ئىشلەيدۇ؛ LLM، embedding ۋە OCR مودېللىرى **Ollama** ۋە **Hugging Face** ئارقىلىق چۈشۈرۈلىدۇ ۋە ھېچقانداق سانلىق مەلۇمات سىرتقا ئەۋەتىلمەيدۇ.

## ئومۇمىي قۇرۇلما

تۈر ئىككى ئاساسىي قىسىمدىن تەركىب تاپىدۇ:

- **Frontend**: Next.js (React) ئاساسىدىكى تور ئارايۈزى. ئىشلەتكۈچىلەر notebook قۇرىدۇ، ھۆججەتلەرنى يۈكلەيدۇ، سۆھبەتلىشىدۇ ۋە MSSQL سەپلىمىسىنى قىلىدۇ.
- **Backend**: Flask (Python) ئاساسىدىكى REST API. RAG ماتورى، ھۆججەتلەرنى ئىندېكسلەش، ۋېكتورلۇق ئىزدەش، MSSQL ئۇلىنىشى ۋە LLM ئارقىلىق جاۋاب يارىتىش ئەمەلىيەتلىرىنى ئورۇندايدۇ.

Backend ئىچىدە:
- **SQLite** سانلىق مەلۇمات ئامبىرى (`app.db`) notebook، سۆھبەت، ئۆي ۋە MSSQL سەپلىمە ئۇچۇرلىرىنى ساقلايدۇ.
- **Chroma** ۋېكتورلۇق سانلىق مەلۇمات ئامبىرى، ھەر بىر ھۆججەت ئۆيى ئۈچۈن ئايرىم ھۆججەت قىسقۇچىدا ۋېكتورلارنى ساقلايدۇ.
- **LangChain / LangGraph** RAG pipeline'نى باشقۇرىدۇ.
- **گىبرىد Retriever** (BM25 + سېمانتىكىلىق ئىزدەش) ۋە **CrossEncoderReranker** ئەڭ مۇناسىۋەتلىك بۆلەكلەرنى تاللايدۇ.

## ئىشلىتىلىدىغان تېخنولوگىيەلەر ۋە مودېللار

| مەقسەت | تېخنولوگىيە / مودېل |
|--------------------------|-----------------------------------------------------------------------------------------------------------|
| **تور Framework (Backend)** | Flask 3.0 |
| **تور Framework (Frontend)** | Next.js 16 + React 19 + Tailwind CSS 4 |
| **ۋېكتورلۇق سانلىق مەلۇمات ئامبىرى** | Chroma (langchain-chroma) |
| **Embedding مودېلى** | `bge-m3` (OllamaEmbeddings ئارقىلىق) |
| **LLM (جاۋاب يارىتىش)** | `qwen2.5:7b-instruct` (Ollama ئارقىلىق، سوئالنى ئەڭ ياخشىلاش ۋە قايتا تەرتىپلەش ئۈچۈنمۇ ئىشلىتىلىدۇ) |
| **OCR مودېلى** | `tiiuae/Falcon-OCR` (Hugging Face transformers، رەسىملەر ۋە سكانېرلانغان PDF'لەر ئۈچۈن) |
| **PDF بىر تەرەپ قىلىش** | PyMuPDF (fitz) + LangChain PyMuPDFLoader؛ سكانېرلانغان بەتلەر ئۈچۈن Falcon-OCR fallback |
| **سانلىق مەلۇمات ئامبىرى** | SQLite (Flask-SQLAlchemy) |
| **MSSQL ئۇلىنىشى** | `pyodbc` + `ODBC Driver 18 for SQL Server` |
| **شىفىرلاش** | Fernet (cryptography) بىلەن MSSQL پارولى شىفىرلىنىدۇ |
| **ھۆججەت ئايلاندۇرۇش** | LibreOffice (headless) كونا .doc/.ppt ۋە .docx/.pptx لارنى PDF'كە ئايلاندۇرىدۇ |

## قاچىلاش

### ئالدىنقى تەلەپلەر

- **Python 3.10+** (backend)
- **Node.js 20+** ۋە **pnpm** ياكى **npm** (frontend)
- **Ollama** قاچىلانغان ۋە ئىشلەۋاتقان بولۇشى كېرەك ([ollama.com](https://ollama.com))
- **LibreOffice** – بەزى ھۆججەت فورماتلىرىنى PDF'كە ئايلاندۇرۇش ئۈچۈن:
  - Ubuntu/Debian: `sudo apt-get install -y libreoffice`
  - Windows/macOS: [LibreOffice چۈشۈرۈش](https://www.libreoffice.org/download/)
- **ODBC Driver 18 for SQL Server** (ئەگەر MSSQL ئىشلەتسىڭىز):
  - Microsoft'نىڭ رەسمىي قاچىلاش كۆرسەتمىسى: [Linux](https://learn.microsoft.com/sql/connect/odbc/linux-mac/installing-the-microsoft-odbc-driver-for-sql-server)، [Windows](https://learn.microsoft.com/sql/connect/odbc/windows/system-requirements-installation-and-driver-files)
- **Git** (مەجبۇرىي ئەمەس)

### Backend قاچىلاش

```bash
cd backend
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### Frontend قاچىلاش

تۈرنىڭ يىلتىز ھۆججەت قىسقۇچىدىن:

```bash
pnpm install     # ياكى npm install
```

### Ollama مودېللىرىنى چۈشۈرۈش

Ollama'نى ئىشلەتكۈزۈشتىن ئىلگىرى كېرەكلىك مودېللارنى چۈشۈرۈڭ:

```bash
ollama pull bge-m3
ollama pull qwen2.5:7b-instruct
```

> **ئەسكەرتىش:** `bge-m3` embedding ئۈچۈن، `qwen2.5:7b-instruct` جاۋاب يارىتىش ۋە قايتا تەرتىپلەش ئۈچۈن ئىشلىتىلىدۇ. مودېل چوڭلۇقى چوڭ بولۇشى مۇمكىن (bge-m3 ~1.2GB، qwen2.5:7b ~4.7GB).

OCR مودېلى **Ollama'دا يوق**؛ Hugging Face'تىن ئاپتوماتىك ھالدا چۈشۈرۈلىدۇ (تۇنجى قېتىم ئىشلەتكەندە). ئەگەر خالىسىڭىز قولدا چۈشۈرەلەيسىز:

```bash
python -c "from transformers import AutoModelForCausalLM; model = AutoModelForCausalLM.from_pretrained('tiiuae/Falcon-OCR', trust_remote_code=True); model.save_pretrained('./models/falcon-ocr')"
```

### مۇھىت ئۆزگەرگۈچىلىرى (.env)

Backend، `backend/rag.env` ھۆججىتىدىن تەڭشەكلەرنى ئوقۇيدۇ. تۆۋەندىكى مەزمۇن بىلەن `rag.env` ھۆججىتىنى قۇرۇڭ:

```ini
# Ollama تەڭشەكلىرى
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:7b-instruct

# Embedding مودېلى
EMBED_MODEL=bge-m3

# ۋېكتورلۇق سانلىق مەلۇمات ئامبىرى ھۆججەت قىسقۇچى
RAG_ROOMS_ROOT=./rag_rooms

# MSSQL شىفىرلاش ئاچقۇچى (Fernet)
# يېڭى ئاچقۇچ يارىتىش ئۈچۈن:
# python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
MSSQL_ENC_KEY=بۇ_جايدا_يارىتىلغان_ئاچقۇچ

# MSSQL ODBC قوزغاتقۇچى (كۆمۈسكە: ODBC Driver 18 for SQL Server)
MSSQL_ODBC_DRIVER=ODBC Driver 18 for SQL Server

# OCR مودېلى (مەجبۇرىي ئەمەس)
FALCON_OCR_MODEL_ID=tiiuae/Falcon-OCR
FALCON_OCR_LOCAL_PATH=./models/falcon-ocr

# ئىختىيارىي قوشۇمچە تەڭشەكلەر
APP_BASE_URL=http://127.0.0.1:5000
DATABASE_URL=sqlite:///app.db
```

**مۇھىم:** `MSSQL_ENC_KEY` بولمىسا، MSSQL ئۇلىنىشى قۇرۇلمايدۇ. بوش قالدۇرسىڭىز، پروگرامما خاتالىق بېرىدۇ.

## پروگراممىنى ئىشلەتكۈزۈش

### 1. Ollama'نى ئىشلەتكۈزۈڭ

```bash
ollama serve
```

مۇلازىمەتنىڭ ئىشلەۋاتقانلىقىنى تەكشۈرۈش ئۈچۈن:

```bash
curl http://localhost:11434
```

ياكى توركۆرگۈچتە `http://localhost:11434` مەنزىلىگە كىرىڭ.

### 2. Backend'نى ئىشلەتكۈزۈڭ

يېڭى تېرمىنالدا:

```bash
cd backend
source venv/bin/activate   # Windows: venv\Scripts\activate
flask --app app.py run
```

Backend كۆمۈسكە بويىچە `http://127.0.0.1:5000` مەنزىلىدە تىڭشايدۇ.

### 3. Frontend'نى ئىشلەتكۈزۈڭ

باشقا تېرمىنالدا (تۈرنىڭ يىلتىز ھۆججەت قىسقۇچىدىن):

```bash
npm run dev
```

ياكى

```bash
pnpm run dev
```

Frontend `http://localhost:3000` مەنزىلىدە ئېچىلىدۇ.

## ئىشلىتىش

### Notebook قۇرۇش ۋە ھۆججەتلەرنى يۈكلەش

1. توركۆرگۈچتە `http://localhost:3000` مەنزىلىگە كىرىڭ.
2. يۇقىرى ئوڭ تەرەپتىكى **"New Notebook"** كۇنۇپكىسىنى بېسىپ، ئىسىم بېرىڭ.
3. Notebook'نى بېسىپ، سۆھبەت بېتىگە كىرىڭ.
4. سول تاختايدىكى **"Sources"** بۆلۈمىدىن ھۆججەتنى سۆرەپ تاشلاڭ ياكى **"Drop files here"** رايونىنى بېسىپ، ھۆججەتلەرنى تاللاڭ.
5. يۈكلەنگەن ھۆججەتلەر ئاپتوماتىك ھالدا ۋېكتورلۇق سانلىق مەلۇمات ئامبىرىغا قوشۇلىدۇ ۋە **تاللانغان** ھالەتكە كېلىدۇ. بىر نەچچە ھۆججەتنى تاللاپ، بىر ۋاقىتتا سوئال سورىيالايسىز.

### سوئال سوراش (RAG)

- سۆھبەت ئېكرانىدا سوئالىڭىزنى يېزىپ، Enter كۇنۇپكىسىنى بېسىڭ.
- سىستېما ئاۋۋال ۋېكتورلۇق ئىزدەش ئېلىپ بارىدۇ، ئەڭ مۇناسىۋەتلىك بۆلەكلەرنى تاللايدۇ ۋە **qwen2.5:7b-instruct** ئارقىلىق جاۋاب يارىتىدۇ.
- جاۋابلاردا `[[c:N]]` بەلگىلىرى بىلەن مەنبە كۆرسىتىلىدۇ؛ بېسىپ، نەقىل كەلتۈرۈلگەن بەتنى/تېكىستنى كۆرەلەيسىز.

### MSSQL سانلىق مەلۇمات ئامبىرىغا ئۇلىنىش

MSSQL'نى notebook'غا ئۇلاش ئۈچۈن:

1. ئاساسىي بەتتىكى **"Data Sources"** بۆلۈمىدە notebook'نى تاللاڭ.
2. **MSSQL Configuration** تاختىسىدا تۆۋەندىكى ساھەلەرنى تولدۇرۇڭ:
   1. **Server** – مۇلازىمېتىر ئىسمى ياكى IP
   2. **Port** – ئادەتتە 1433
   3. **Database Name** – سانلىق مەلۇمات ئامبىرى ئىسمى
   4. **Username** – ئىشلەتكۈچى ئىسمى
   5. **Password** – پارول (يېڭىلاشدا بوش قالدۇرسىڭىز، كونا پارول ساقلىنىدۇ)
   6. **Table Name** – سوئال سورىلىدىغان جەدۋەل ئىسمى
   7. **Timestamp Column** – ۋاقىت بەلگىسى ئىستۇنى (ئەڭ يېڭى خاتىرىلەرنى تەرتىپلەش ئۈچۈن)
   8. **Text Columns** – تېكىستلىك ئىستۇنلار (ئۈتۈر بىلەن ئايرىڭ، مىس. `message, level, source`)
3. **"Save & Test Connection"** كۇنۇپكىسىنى بېسىڭ. Backend ئۇلىنىشنى سىنايدۇ؛ مۇۋەپپەقىيەتلىك بولسا ساقلايدۇ.
4. Notebook'غا كىرىپ، سۆھبەت ئېكرانىدا **"SQL Source"** دەپ ئاتالغان مەنبەنى تاللاڭ.
5. سوئاللىرىڭىزنى تەبىئىي تىلدا سوراڭ؛ سىستېما ھەم ھۆججەتلەردىن، ھەم MSSQL'دىن كەلگەن سانلىق مەلۇماتلار بىلەن جاۋاب يارىتىدۇ.

## قوللىنىدىغان ھۆججەت فورماتلىرى

تۆۋەندىكى فورماتلار يۈكلىنىپ، RAG'دا ئىشلىتىلىشى مۇمكىن:

```
.pdf   .md    .txt   .docx  .pptx  .doc   .ppt
.jpg   .jpeg  .png
```

- **PDF**: تېكىست قاتلامى بار بولسا بىۋاسىتە ئوقۇلىدۇ؛ سكانېرلانغان/رەسىملىك PDF'لەردە Falcon-OCR ئىشلىتىلىدۇ.
- **رەسىملەر**: تولۇق بەت OCR ئارقىلىق تېكىستكە ئايلاندۇرۇلىدۇ.
- **Word/PowerPoint**: تېكىست ۋە ئىچىدىكى رەسىملەر ئايرىم بىر تەرەپ قىلىنىدۇ (رەسىملەر OCR قىلىنىدۇ).
- **كونا .doc/.ppt**: LibreOffice ئارقىلىق .docx/.pptx'كە ئايلاندۇرۇلۇپ بىر تەرەپ قىلىنىدۇ.

## مەسىلىلەرنى ھەل قىلىش

### Ollama ئۇلىنىش خاتالىقى

- `ollama serve` ئىشلەۋاتامدۇ؟ تەكشۈرۈڭ.
- `OLLAMA_BASE_URL` توغرامۇ؟ كۆمۈسكە `http://localhost:11434`.
- مودېللار چۈشۈرۈلدىمۇ؟ `ollama list` بىلەن تەكشۈرۈڭ.

### Backend ئىشلەنمەيدۇ

- `requirements.txt'تىكى` باغلىنىشلار قاچىلانغانلىقىنى تەكشۈرۈڭ.
- `rag.env` ھۆججىتىنىڭ `backend/` ھۆججەت قىسقۇچىدا بارلىقىنى تەكشۈرۈڭ.
- SQLite ھۆججىتى (`app.db`) يارىتىلالىشى ئۈچۈن ھۆججەت قىسقۇچقا يېزىش ھوقۇقى بېرىڭ.

### MSSQL ئۇلىنىش خاتالىقى

- `MSSQL_ENC_KEY` ئېنىقلانغانمۇ ۋە ئىناۋەتلىك Fernet ئاچقۇچىمۇ؟
- ODBC Driver 18 قاچىلانغانمۇ؟
- مۇلازىمېتىر، پورت، سانلىق مەلۇمات ئامبىرى ئىسمى ۋە جەدۋەل ئىسمى توغرامۇ؟
- جەدۋەل/ئىستۇن ئىسىملىرىدە ئالاھىدە بەلگىلەر ياكى بوش ئورۇن بولماسلىقى كېرەك (پەقەت ھەرىپلەر، سانلار ۋە `_`).

### LibreOffice خاتالىقى

بەزى فورماتلارنى PDF'كە ئايلاندۇرۇش ئۈچۈن `soffice` بۇيرۇقى كېرەك. قاچىلانمىغان بولسا:

```bash
sudo apt-get install -y libreoffice
```

### OCR ئاستا ياكى GPU خاتالىقى

Falcon-OCR مودېلى چوڭ؛ CPU'دا ئاستا ئىشلىشى مۇمكىن. GPU بولمىسا، سەۋر قىلىڭ ياكى كىچىكرەك OCR مودېلىنى ئىشلىتىڭ.

---

## بىخەتەرلىك ئەسكەرتىشلىرى

- MSSQL پارولى **Fernet** بىلەن شىفىرلىنىپ، سانلىق مەلۇمات ئامبىرىدا ساقلىنىدۇ؛ API ھەرگىز پارولنى قايتۇرمايدۇ.
- SQL سوئاللىرىدا جەدۋەل/ئىستۇن ئىسىملىرى قاتتىق ئاق تىزىملىك بىلەن تەكشۈرۈلىدۇ (injection'نىڭ ئالدىنى ئالىدۇ).
- سىستېما پۈتۈنلەي يەرلىك ئىشلەيدۇ؛ ھۆججەتلىرىڭىز ۋە سوئاللىرىڭىز سىرتقا چىقمايدۇ.
- شۇنداق بولسىمۇ، ھەسسىياتلىق سانلىق مەلۇماتلار بىلەن ئىشلەتكەندە، تور كىرىشىنى چەكلەش تەۋسىيە قىلىنىدۇ.
