# RAG Жүйесі (Көп Дереккөзді Қолдайды)

Бұл жоба толығымен жергілікті түрде жұмыс істейтін **Retrieval-Augmented Generation (RAG)** жүйесі. PDF, Word, PowerPoint, сурет, мәтіндік файлдар және MSSQL дерекқоры сияқты әртүрлі дереккөздерді пайдаланып, табиғи тілде сұрақтар қойып, құжаттарға негізделген жауаптар ала аласыз.

Жүйе толығымен **жергілікті** жұмыс істейді; LLM, embedding және OCR модельдері **Ollama** және **Hugging Face** арқылы жүктеледі және ешбір деректер сыртқа жіберілмейді.

## Жалпы Сәулет

Жоба екі негізгі бөліктен тұрады:

- **Frontend**: Next.js (React) негізіндегі веб-интерфейс. Пайдаланушылар notebook құрады, файлдар жүктейді, сөйлеседі және MSSQL конфигурациясын жасайды.
- **Backend**: Flask (Python) негізіндегі REST API. RAG қозғалтқышын, құжаттарды индекстеуді, векторлық іздеуді, MSSQL байланысын және LLM арқылы жауап генерациялауды орындайды.

Backend ішінде:
- **SQLite** дерекқоры (`app.db`) notebook, сөйлесу, бөлме және MSSQL конфигурация деректерін сақтайды.
- **Chroma** векторлық дерекқоры әрбір құжат бөлмесі үшін жеке қалтада векторларды сақтайды.
- **LangChain / LangGraph** RAG pipeline-ын басқарады.
- **Гибридті Retriever** (BM25 + семантикалық іздеу) және **CrossEncoderReranker** ең өзекті бөліктерді таңдайды.

## Қолданылатын Технологиялар мен Модельдер

| Мақсаты | Технология / Модель |
|--------------------------|-----------------------------------------------------------------------------------------------------------|
| **Веб Framework (Backend)** | Flask 3.0 |
| **Веб Framework (Frontend)** | Next.js 16 + React 19 + Tailwind CSS 4 |
| **Векторлық Дерекқор** | Chroma (langchain-chroma) |
| **Embedding Моделі** | `bge-m3` (OllamaEmbeddings арқылы) |
| **LLM (Жауап Генерациясы)** | `qwen2.5:7b-instruct` (Ollama арқылы, сондай-ақ сұрақты оңтайландыру және қайта реттеу үшін қолданылады) |
| **OCR Моделі** | `tiiuae/Falcon-OCR` (Hugging Face transformers, суреттер және сканерленген PDF-лер үшін) |
| **PDF Өңдеу** | PyMuPDF (fitz) + LangChain PyMuPDFLoader; сканерленген беттер үшін Falcon-OCR fallback |
| **Дерекқор** | SQLite (Flask-SQLAlchemy) |
| **MSSQL Байланысы** | `pyodbc` + `ODBC Driver 18 for SQL Server` |
| **Шифрлау** | Fernet (cryptography) арқылы MSSQL құпия сөзі шифрланады |
| **Файл Конверсиялары** | LibreOffice (headless) ескі .doc/.ppt және .docx/.pptx файлдарын PDF-ке түрлендіреді |

## Орнату

### Алдын ала талаптар

- **Python 3.10+** (backend)
- **Node.js 20+** және **pnpm** немесе **npm** (frontend)
- **Ollama** орнатылған және жұмыс істеп тұр ([ollama.com](https://ollama.com))
- **LibreOffice** – кейбір файл пішімдерін PDF-ке түрлендіру үшін:
  - Ubuntu/Debian: `sudo apt-get install -y libreoffice`
  - Windows/macOS: [LibreOffice жүктеу](https://www.libreoffice.org/download/)
- **ODBC Driver 18 for SQL Server** (егер MSSQL пайдалансаңыз):
  - Microsoft-тың ресми орнату нұсқаулығы: [Linux](https://learn.microsoft.com/sql/connect/odbc/linux-mac/installing-the-microsoft-odbc-driver-for-sql-server), [Windows](https://learn.microsoft.com/sql/connect/odbc/windows/system-requirements-installation-and-driver-files)
- **Git** (міндетті емес)

### Backend Орнату

```bash
cd backend
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### Frontend Орнату

Жобаның түбірлік қалтасынан:

```bash
pnpm install     # немесе npm install
```

### Ollama Модельдерін Жүктеу

Ollama-ны іске қоспас бұрын қажетті модельдерді жүктеңіз:

```bash
ollama pull bge-m3
ollama pull qwen2.5:7b-instruct
```

> **Ескерту:** `bge-m3` embedding үшін, `qwen2.5:7b-instruct` жауап генерациялау және қайта реттеу үшін қолданылады. Модель өлшемдері үлкен болуы мүмкін (bge-m3 ~1.2GB, qwen2.5:7b ~4.7GB).

OCR моделі **Ollama-да жоқ**; Hugging Face-тен автоматты түрде жүктеледі (алғашқы қолдануда). Қаласаңыз қолмен де жүктей аласыз:

```bash
python -c "from transformers import AutoModelForCausalLM; model = AutoModelForCausalLM.from_pretrained('tiiuae/Falcon-OCR', trust_remote_code=True); model.save_pretrained('./models/falcon-ocr')"
```

### Қоршаған Орта Айнымалылары (.env)

Backend, `backend/rag.env` файлынан параметрлерді оқиды. Төмендегі мазмұнмен `rag.env` файлын жасаңыз:

```ini
# Ollama параметрлері
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:7b-instruct

# Embedding моделі
EMBED_MODEL=bge-m3

# Векторлық дерекқор қалтасы
RAG_ROOMS_ROOT=./rag_rooms

# MSSQL шифрлау кілті (Fernet)
# Жаңа кілтті генерациялау үшін:
# python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
MSSQL_ENC_KEY=осы_жерге_генерацияланған_кілт

# MSSQL ODBC драйвері (әдепкі: ODBC Driver 18 for SQL Server)
MSSQL_ODBC_DRIVER=ODBC Driver 18 for SQL Server

# OCR моделі (міндетті емес)
FALCON_OCR_MODEL_ID=tiiuae/Falcon-OCR
FALCON_OCR_LOCAL_PATH=./models/falcon-ocr

# Қосымша параметрлер
APP_BASE_URL=http://127.0.0.1:5000
DATABASE_URL=sqlite:///app.db
```

**Маңызды:** `MSSQL_ENC_KEY` болмаса, MSSQL байланысы орнатылмайды. Бос қалдырсаңыз, қосымша қате береді.

## Қосымшаны Іске Қосу

### 1. Ollama-ны іске қосыңыз

```bash
ollama serve
```

Қызметтің жұмыс істеп тұрғанын тексеру үшін:

```bash
curl http://localhost:11434
```

немесе браузерде `http://localhost:11434` мекенжайына өтіңіз.

### 2. Backend-ті іске қосыңыз

Жаңа терминалда:

```bash
cd backend
source venv/bin/activate   # Windows: venv\Scripts\activate
flask --app app.py run
```

Backend әдепкі бойынша `http://127.0.0.1:5000` мекенжайында тыңдайды.

### 3. Frontend-ті іске қосыңыз

Басқа терминалда (жобаның түбірлік қалтасынан):

```bash
npm run dev
```

немесе

```bash
pnpm run dev
```

Frontend `http://localhost:3000` мекенжайында ашылады.

## Қолдану

### Notebook Құру және Файлдарды Жүктеу

1. Браузерде `http://localhost:3000` мекенжайына өтіңіз.
2. Жоғарғы оң жақтағы **"New Notebook"** батырмасын басып, атау беріңіз.
3. Notebook-ты басып, сөйлесу бетіне өтіңіз.
4. Сол панельдегі **"Sources"** бөлімінен файлды сүйреп апарып тастаңыз немесе **"Drop files here"** аймағын басып, файлдарды таңдаңыз.
5. Жүктелген құжаттар автоматты түрде векторлық дерекқорға қосылады және **таңдалған** күйге келеді. Бірнеше құжатты таңдап, бір уақытта сұраулар қоюға болады.

### Сұрақ Қою (RAG)

- Сөйлесу экранында сұрағыңызды жазып, Enter-ді басыңыз.
- Жүйе алдымен векторлық іздеу жүргізеді, ең өзекті бөліктерді таңдайды және **qwen2.5:7b-instruct** арқылы жауап генерациялайды.
- Жауаптарда `[[c:N]]` белгілерімен дереккөз көрсетіледі; басып, дәйексөз келтірілген бетті/мәтінді көре аласыз.

### MSSQL Дерекқорына Қосылу

MSSQL-ді notebook-қа қосу үшін:

1. Негізгі беттегі **"Data Sources"** бөлімінде notebook-ты таңдаңыз.
2. **MSSQL Configuration** панелінде келесі өрістерді толтырыңыз:
   1. **Server** – Сервер атауы немесе IP
   2. **Port** – Әдетте 1433
   3. **Database Name** – Дерекқор атауы
   4. **Username** – Пайдаланушы аты
   5. **Password** – Құпия сөз (жаңарту кезінде бос қалдырса, ескі құпия сөз сақталады)
   6. **Table Name** – Сұралатын кесте атауы
   7. **Timestamp Column** – Уақыт белгісі бағанасы (ең жаңа жазбаларды сұрыптау үшін)
   8. **Text Columns** – Мәтіндік бағаналар (үтірмен бөліңіз, мыс. `message, level, source`)
3. **"Save & Test Connection"** батырмасын басыңыз. Backend байланысты тексереді; сәтті болса сақтайды.
4. Notebook-қа өтіп, сөйлесу экранында **"SQL Source"** деп аталатын дереккөзді таңдаңыз.
5. Сұрақтарыңызды табиғи тілде қойыңыз; жүйе құжаттардан да, MSSQL-ден келген деректерден де жауап генерациялайды.

## Қолдау Көрсетілетін Файл Пішімдері

Төмендегі пішімдер жүктеліп, RAG-де қолданыла алады:

```
.pdf   .md    .txt   .docx  .pptx  .doc   .ppt
.jpg   .jpeg  .png
```

- **PDF**: Мәтін қабаты бар болса тікелей оқылады; сканерленген/суретті PDF-лерде Falcon-OCR іске қосылады.
- **Суреттер**: Толық бет OCR арқылы мәтінге түрлендіріледі.
- **Word/PowerPoint**: Мәтін және кірістірілген суреттер бөлек өңделеді (суреттер OCR-ланады).
- **Ескі .doc/.ppt**: LibreOffice арқылы .docx/.pptx-ке түрлендіріліп өңделеді.

## Ақаулықтарды Түзету

### Ollama байланыс қатесі

- `ollama serve` жұмыс істеп тұр ма? Тексеріңіз.
- `OLLAMA_BASE_URL` дұрыс па? Әдепкі `http://localhost:11434`.
- Модельдер жүктелді ме? `ollama list` арқылы тексеріңіз.

### Backend іске қосылмайды

- `requirements.txt`-тегі тәуелділіктердің орнатылғанына көз жеткізіңіз.
- `rag.env` файлының `backend/` қалтасында бар екенін тексеріңіз.
- SQLite файлы (`app.db`) жасала алуы үшін қалтаға жазу рұқсатын беріңіз.

### MSSQL байланыс қатесі

- `MSSQL_ENC_KEY` анықталған және жарамды Fernet кілті ме?
- ODBC Driver 18 орнатылған ба?
- Сервер, порт, дерекқор атауы және кесте атауы дұрыс па?
- Кесте/баған атауларында арнайы таңбалар немесе бос орын болмауы керек (тек әріптер, сандар және `_`).

### LibreOffice қатесі

Кейбір пішімдерді PDF-ке түрлендіру үшін `soffice` командасы қажет. Орнатылмаған болса:

```bash
sudo apt-get install -y libreoffice
```

### OCR баяу немесе GPU қатесі

Falcon-OCR моделі үлкен; CPU-да баяу жұмыс істеуі мүмкін. GPU жоқ болса, сабырлы болыңыз немесе кішірек OCR моделін пайдаланыңыз.

## Қауіпсіздік Ескертпелері

- MSSQL құпия сөзі **Fernet** арқылы шифрланып, дерекқорда сақталады; API ешқашан құпия сөзді қайтармайды.
- SQL сұрауларында кесте/баған атаулары қатаң ақ тізіммен тексеріледі (инъекцияның алды алынады).
- Жүйе толығымен жергілікті жұмыс істейді; құжаттарыңыз бен сұрауларыңыз сыртқа шықпайды.
- Дегенмен, сезімтал деректермен пайдаланғанда, желілік кіруді шектеу ұсынылады.
