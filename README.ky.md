# RAG Системасы (Көп Булактуу Колдоо)

Бул долбоор толугу менен жергиликтүү түрдө иштеген **Retrieval-Augmented Generation (RAG)** системасы. PDF, Word, PowerPoint, сүрөт, тексттик файлдар жана MSSQL маалымат базасы сыяктуу ар кандай булактарды колдонуп, табигый тилде суроолор берип, документтерге негизделген жооптор ала аласыз.

Система толугу менен **жергиликтүү** иштейт; LLM, embedding жана OCR моделдери **Ollama** жана **Hugging Face** аркылуу жүктөлөт жана эч кандай маалыматтар сыртка жөнөтүлбөйт.

## Жалпы Архитектура

Долбоор эки негизги бөлүктөн турат:

- **Frontend**: Next.js (React) негизиндеги веб-интерфейс. Колдонуучулар notebook түзөт, файлдарды жүктөйт, сүйлөшөт жана MSSQL конфигурациясын жасайт.
- **Backend**: Flask (Python) негизиндеги REST API. RAG кыймылдаткычын, документтерди индекстөөнү, вектордук издөөнү, MSSQL байланышын жана LLM аркылуу жоопторду генерациялоону аткарат.

Backend ичинде:
- **SQLite** маалымат базасы (`app.db`) notebook, сүйлөшүү, бөлмө жана MSSQL конфигурация маалыматтарын сактайт.
- **Chroma** вектордук маалымат базасы ар бир документ бөлмөсү үчүн өзүнчө папкада векторлорду сактайт.
- **LangChain / LangGraph** RAG pipeline-ын башкарат.
- **Гибриддик Retriever** (BM25 + семантикалык издөө) жана **CrossEncoderReranker** эң актуалдуу бөлүктөрдү тандайт.

## Колдонулган Технологиялар жана Моделдер

| Максаты | Технология / Модель |
|--------------------------|-----------------------------------------------------------------------------------------------------------|
| **Веб Framework (Backend)** | Flask 3.0 |
| **Веб Framework (Frontend)** | Next.js 16 + React 19 + Tailwind CSS 4 |
| **Вектордук Маалымат Базасы** | Chroma (langchain-chroma) |
| **Embedding Модели** | `bge-m3` (OllamaEmbeddings аркылуу) |
| **LLM (Жооп Генерациясы)** | `qwen2.5:7b-instruct` (Ollama аркылуу, ошондой эле суроону оптималдаштыруу жана кайра иреттөө үчүн колдонулат) |
| **OCR Модели** | `tiiuae/Falcon-OCR` (Hugging Face transformers, сүрөттөр жана сканерленген PDF'тер үчүн) |
| **PDF Иштетүү** | PyMuPDF (fitz) + LangChain PyMuPDFLoader; сканерленген барактар үчүн Falcon-OCR fallback |
| **Маалымат Базасы** | SQLite (Flask-SQLAlchemy) |
| **MSSQL Байланышы** | `pyodbc` + `ODBC Driver 18 for SQL Server` |
| **Шифрлөө** | Fernet (cryptography) аркылуу MSSQL сырсөзү шифрленет |
| **Файл Конверсиялары** | LibreOffice (headless) эски .doc/.ppt жана .docx/.pptx файлдарын PDF-ге айландырат |

## Орнотуу

### Алдын ала талаптар

- **Python 3.10+** (backend)
- **Node.js 20+** жана **pnpm** же **npm** (frontend)
- **Ollama** орнотулган жана иштеп жатат ([ollama.com](https://ollama.com))
- **LibreOffice** – кээ бир файл форматтарын PDF-ге айландыруу үчүн:
  - Ubuntu/Debian: `sudo apt-get install -y libreoffice`
  - Windows/macOS: [LibreOffice жүктөө](https://www.libreoffice.org/download/)
- **ODBC Driver 18 for SQL Server** (эгер MSSQL колдонсоңуз):
  - Microsoft'тун расмий орнотуу нускамасы: [Linux](https://learn.microsoft.com/sql/connect/odbc/linux-mac/installing-the-microsoft-odbc-driver-for-sql-server), [Windows](https://learn.microsoft.com/sql/connect/odbc/windows/system-requirements-installation-and-driver-files)
- **Git** (милдеттүү эмес)

### Backend Орнотуу

```bash
cd backend
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### Frontend Орнотуу

Долбоордун тамыр папкасынан:

```bash
pnpm install     # же npm install
```

### Ollama Моделдерин Жүктөө

Ollama-ны ишке киргизүүдөн мурун керектүү моделдерди жүктөңүз:

```bash
ollama pull bge-m3
ollama pull qwen2.5:7b-instruct
```

> **Эскертүү:** `bge-m3` embedding үчүн, `qwen2.5:7b-instruct` жооп генерациялоо жана кайра иреттөө үчүн колдонулат. Модель өлчөмдөрү чоң болушу мүмкүн (bge-m3 ~1.2GB, qwen2.5:7b ~4.7GB).

OCR модели **Ollama'да жок**; Hugging Face'тен автоматтык түрдө жүктөлөт (биринчи колдонууда). Кааласаңыз кол менен да жүктөй аласыз:

```bash
python -c "from transformers import AutoModelForCausalLM; model = AutoModelForCausalLM.from_pretrained('tiiuae/Falcon-OCR', trust_remote_code=True); model.save_pretrained('./models/falcon-ocr')"
```

### Чөйрө Өзгөрмөлөрү (.env)

Backend, `backend/rag.env` файлынан параметрлерди окуйт. Төмөнкү мазмун менен `rag.env` файлын түзүңүз:

```ini
# Ollama параметрлери
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:7b-instruct

# Embedding модели
EMBED_MODEL=bge-m3

# Вектордук маалымат базасынын папкасы
RAG_ROOMS_ROOT=./rag_rooms

# MSSQL шифрлөө ачкычы (Fernet)
# Жаңы ачкычты генерациялоо үчүн:
# python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
MSSQL_ENC_KEY=бул_жерге_генерацияланган_ачкыч

# MSSQL ODBC драйвери (көмүскө: ODBC Driver 18 for SQL Server)
MSSQL_ODBC_DRIVER=ODBC Driver 18 for SQL Server

# OCR модели (милдеттүү эмес)
FALCON_OCR_MODEL_ID=tiiuae/Falcon-OCR
FALCON_OCR_LOCAL_PATH=./models/falcon-ocr

# Кошумча параметрлер
APP_BASE_URL=http://127.0.0.1:5000
DATABASE_URL=sqlite:///app.db
```

**Маанилүү:** `MSSQL_ENC_KEY` жок болсо, MSSQL байланышы орнотулбайт. Бош калтырсаңыз, колдонмо ката берет.

## Колдонмону Ишке Киргизүү

### 1. Ollama-ны ишке киргизиңиз

```bash
ollama serve
```

Кызматтын иштеп жатканын текшерүү үчүн:

```bash
curl http://localhost:11434
```

же браузерде `http://localhost:11434` дарегине өтүңүз.

### 2. Backend-ти ишке киргизиңиз

Жаңы терминалда:

```bash
cd backend
source venv/bin/activate   # Windows: venv\Scripts\activate
flask --app app.py run
```

Backend көмүскө түрдө `http://127.0.0.1:5000` дарегинде угат.

### 3. Frontend-ти ишке киргизиңиз

Башка терминалда (долбоордун тамыр папкасынан):

```bash
npm run dev
```

же

```bash
pnpm run dev
```

Frontend `http://localhost:3000` дарегинде ачылат.

## Колдонуу

### Notebook Түзүү жана Файлдарды Жүктөө

1. Браузерде `http://localhost:3000` дарегине өтүңүз.
2. Жогорку оң жактагы **"New Notebook"** баскычын басып, аталыш бериңиз.
3. Notebook-ту басып, сүйлөшүү бетине өтүңүз.
4. Сол панелдеги **"Sources"** бөлүмүнөн файлды сүйрөп апарып таштаңыз же **"Drop files here"** аймагын басып, файлдарды тандаңыз.
5. Жүктөлгөн документтер автоматтык түрдө вектордук маалымат базасына кошулат жана **тандалган** абалга келет. Бир нече документти тандап, бир убакта суроолорго алса болот.

### Суроо Берүү (RAG)

- Сүйлөшүү экранында сурооңузду жазып, Enter баскычын басыңыз.
- Система алгач вектордук издөө жүргүзөт, эң актуалдуу бөлүктөрдү тандайт жана **qwen2.5:7b-instruct** аркылуу жооп генерациялайт.
- Жооптордо `[[c:N]]` белгилери менен булак көрсөтүлөт; басып, цитата келтирилген баракты/текстти көрө аласыз.

### MSSQL Маалымат Базасына Туташуу

MSSQL-ди notebook-ко туташтыруу үчүн:

1. Негизги беттеги **"Data Sources"** бөлүмүндө notebook-ту тандаңыз.
2. **MSSQL Configuration** панелинде төмөнкү талааларды толтуруңуз:
   1. **Server** – Сервердин аты же IP
   2. **Port** – Адатта 1433
   3. **Database Name** – Маалымат базасынын аты
   4. **Username** – Колдонуучунун аты
   5. **Password** – Сырсөз (жаңыртууда бош калтырса, эски сырсөз сакталат)
   6. **Table Name** – Суралуучу таблицанын аты
   7. **Timestamp Column** – Убакыт белгиси тилкеси (эң жаңы жазууларды иреттөө үчүн)
   8. **Text Columns** – Тексттик тилкелер (үтүр менен бөлүңүз, мис. `message, level, source`)
3. **"Save & Test Connection"** баскычын басыңыз. Backend байланышты текшерет; ийгиликтүү болсо сактайт.
4. Notebook-ко өтүп, сүйлөшүү экранында **"SQL Source"** деп аталган булакты тандаңыз.
5. Суроолоруңузду табигый тилде бериңиз; система документтерден да, MSSQL'ден келген маалыматтардан да жооп генерациялайт.

## Колдоого Алынган Файл Форматтары

Төмөнкү форматтар жүктөлүп, RAG'де колдонула алат:

```
.pdf   .md    .txt   .docx  .pptx  .doc   .ppt
.jpg   .jpeg  .png
```

- **PDF**: Текст кабаты бар болсо түздөн-түз окулат; сканерленген/сүрөттүү PDF'терде Falcon-OCR ишке кирет.
- **Сүрөттөр**: Толук барак OCR аркылуу текстке айландырылат.
- **Word/PowerPoint**: Текст жана киргизилген сүрөттөр өзүнчө иштетилет (сүрөттөр OCR-ланат).
- **Эски .doc/.ppt**: LibreOffice аркылуу .docx/.pptx-ке айландырылып иштетилет.

## Көйгөйлөрдү Чечүү

### Ollama байланыш катасы

- `ollama serve` иштеп жатабы? Текшериңиз.
- `OLLAMA_BASE_URL` туурабы? Көмүскө `http://localhost:11434`.
- Моделдер жүктөлдүбү? `ollama list` менен текшериңиз.

### Backend ишке кирбейт

- `requirements.txt'теги` көз карандылыктардын орнотулганын текшериңиз.
- `rag.env` файлынын `backend/` папкасында бар экенин текшериңиз.
- SQLite файлы (`app.db`) түзүлүшү үчүн папкага жазуу укугун бериңиз.

### MSSQL байланыш катасы

- `MSSQL_ENC_KEY` аныкталганбы жана жарактуу Fernet ачкычпы?
- ODBC Driver 18 орнотулганбы?
- Сервер, порт, маалымат базасынын аты жана таблицанын аты туурабы?
- Таблица/тилке аттарында атайын белгилер же бош орун болбошу керек (тек тамгалар, сандар жана `_`).

### LibreOffice катасы

Кээ бир форматтарды PDF-ге айландыруу үчүн `soffice` буйругу керек. Орнотулбаса:

```bash
sudo apt-get install -y libreoffice
```

### OCR жай же GPU катасы

Falcon-OCR модели чоң; CPU'да жай иштеши мүмкүн. GPU жок болсо, сабырдуу болуңуз же кичирээк OCR моделинин колдонуңуз.

## Коопсуздук Эскертүүлөрү

- MSSQL сырсөзү **Fernet** менен шифрленип, маалымат базасында сакталат; API эч качан сырсөздү кайтарбайт.
- SQL суроолорунда таблица/тилке аттары катуу ак тизме менен текшерилет (инъекциянын алды алынат).
- Система толугу менен жергиликтүү иштейт; документтериңиз жана суроолоруңуз сыртка чыкпайт.
- Бирок, сезимтал маалыматтар менен колдонгондо, тармактык кирүүнү чектөө сунушталат.
